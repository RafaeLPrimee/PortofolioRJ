Procédures

Ce document regroupe les procédures réalisées lors de la mise en place de l’environnement Active Directory, incluant l’installation des services, la configuration réseau et la gestion des utilisateurs et groupes.

Procédure 1 — VM Windows Server : Installation et mise en place de l’AD

1. Création de la machine virtuelle sur Proxmox

  1. Se connecter à l’interface web de Proxmox.
  2. Cliquer sur Créer une VM.
  3. Donner un nom à la machine, par exemple : SRV-AD
  4. Sélectionner l’image ISO de Windows Server.
  5. Configurer les ressources de la VM :
    • CPU : 2 cœurs minimum
    • RAM : 4 Go minimum
    • Disque : 50 Go minimum
    • Carte réseau : interface reliée au réseau du laboratoire
  6. Terminer la création de la VM.
  7. Démarrer la VM.

2. Installation de Windows Server

  1. Démarrer la VM depuis l’ISO Windows Server.
  2. Sélectionner la langue, le format horaire et le clavier.
  3. Cliquer sur Installer maintenant.
  4. Sélectionner l’édition de Windows Server souhaitée.
  5. Accepter les conditions de licence.
  6. Choisir Installation personnalisée.
  7. Sélectionner le disque virtuel créé sur Proxmox.
  8. Lancer l’installation.
  9. Définir le mot de passe du compte Administrateur.
  10. Se connecter à Windows Server.

3. Configuration du nom du serveur

  1. Ouvrir le Gestionnaire de serveur.
  2. Aller dans Serveur local.
  3. Cliquer sur le nom actuel de l’ordinateur.
  4. Modifier le nom du serveur, par exemple : SRV-AD
  5. Redémarrer le serveur.

4. Configuration de l’adresse IP fixe

Le serveur Active Directory doit disposer d’une adresse IP fixe.

  1. Ouvrir les paramètres réseau.
  2. Accéder aux propriétés de la carte réseau.
  3. Ouvrir IPv4.
  4. Renseigner :
  • Adresse IP : selon le plan d’adressage du réseau
  • Masque : selon le réseau utilisé
  • Passerelle : adresse du routeur
  • DNS préféré : adresse IP du serveur lui-même

Exemple :

Adresse IP : 192.168.1.10
Masque     : 255.255.255.0
Passerelle : 192.168.1.1
DNS        : 192.168.1.10

5. Installation du rôle Active Directory Domain Services

  1. Ouvrir le Gestionnaire de serveur.
  2. Cliquer sur Ajouter des rôles et fonctionnalités.
  3. Sélectionner Installation basée sur un rôle ou une fonctionnalité.
  4. Sélectionner le serveur.
  5. Cocher Services AD DS (Active Directory Domain Services).
  6. Accepter l’installation des fonctionnalités supplémentaires.
  7. Cliquer sur Installer.
  8. Attendre la fin de l’installation.

6. Promotion du serveur en contrôleur de domaine

  1. Dans le Gestionnaire de serveur, cliquer sur la notification.
  2. Sélectionner Promouvoir ce serveur en contrôleur de domaine.
  3. Choisir Ajouter une nouvelle forêt.
  4. Définir le nom du domaine.

Exemple :

Domaine : entreprise.local
  1. Définir le mot de passe DSRM.
  2. Laisser les options DNS proposées.
  3. Vérifier les chemins de stockage.
  4. Cliquer sur Installer.
  5. Le serveur redémarre automatiquement.

7. Vérification

  1. Se connecter avec le compte administrateur du domaine.
  2. Ouvrir Utilisateurs et ordinateurs Active Directory.
  3. Vérifier que le domaine apparaît.
  4. Vérifier la présence du serveur dans les contrôleurs de domaine.

Le serveur est maintenant contrôleur de domaine Active Directory.

Procédure 2 — VM Windows Server : Installation et mise en place du DHCP

1. Préparation

Le service DHCP permet d’attribuer automatiquement aux postes clients une adresse IP, un masque, une passerelle et un serveur DNS.

2. Installation du rôle DHCP

  1. Ouvrir le Gestionnaire de serveur.
  2. Cliquer sur Ajouter des rôles et fonctionnalités.
  3. Choisir Installation basée sur un rôle ou une fonctionnalité.
  4. Sélectionner le serveur.
  5. Cocher Serveur DHCP.
  6. Accepter l’installation des fonctionnalités supplémentaires.
  7. Cliquer sur Installer.

3. Finalisation de l'installation DHCP

  1. Cliquer sur la notification du Gestionnaire de serveur.
  2. Sélectionner Terminer la configuration DHCP.
  3. Suivre l’assistant.
  4. Utiliser les informations du compte administrateur du domaine.
  5. Terminer la configuration.

4. Création d'une étendue DHCP

  1. Ouvrir Outils → DHCP.
  2. Développer le nom du serveur.
  3. Faire un clic droit sur IPv4.
  4. Sélectionner Nouvelle étendue.
  5. Donner un nom à l’étendue.

Exemple :

Nom : LAN-ENTREPRISE
  1. Définir la plage d’adresses.
Début : 192.168.1.100
Fin   : 192.168.1.200
  1. Définir le masque :
255.255.255.0

5. Définition des exclusions

Exemple :

192.168.1.1 → 192.168.1.20

Ces adresses peuvent être exclues de la distribution DHCP.

6. Configuration de la durée du bail

Définir la durée pendant laquelle une adresse IP est attribuée à un poste. La valeur par défaut peut être conservée.

7. Configuration des options DHCP

Configurer notamment :

  • Routeur : 192.168.1.1
  • Serveur DNS : 192.168.1.10
  • Nom de domaine : entreprise.local

8. Activation de l'étendue

  1. Terminer l’assistant.
  2. Ouvrir DHCP → IPv4.
  3. Vérifier que l’étendue est active.

9. Test depuis un poste client

ipconfig /release
ipconfig /renew
ipconfig /all

Vérifier que le poste reçoit une adresse IP, un masque, une passerelle, le serveur DNS et le domaine entreprise.local.

Procédure 3 — VM Windows Server : Installation et mise en place du DNS

Dans un environnement Active Directory, le DNS est indispensable pour permettre aux clients de trouver les services du domaine.

1. Vérification de l'installation

  1. Ouvrir le Gestionnaire de serveur.
  2. Aller dans Outils.
  3. Cliquer sur DNS.

2. Vérification de la zone DNS

  1. Développer le nom du serveur.
  2. Développer Zones de recherche directe.
  3. Vérifier la présence du domaine : entreprise.local.

3. Vérification de la zone inverse

  1. Cliquer sur Zones de recherche inversée.
  2. Sélectionner Nouvelle zone.
  3. Choisir une zone principale.
  4. Sélectionner la zone adaptée au réseau.

Exemple pour 192.168.1.0/24 :

1.168.192.in-addr.arpa

4. Création d'un enregistrement DNS

  1. Ouvrir la zone entreprise.local.
  2. Faire un clic droit.
  3. Sélectionner Nouvel hôte (A ou AAAA).
  4. Renseigner un nom.
Nom : serveur
IP  : 192.168.1.10

On obtient :

serveur.entreprise.local

5. Test du DNS

nslookup serveur.entreprise.local
ping serveur.entreprise.local

Si le nom est correctement résolu, le service DNS fonctionne.

Procédure 4 — VM Windows Server : Mise en place des OU / Groupes / Utilisateurs

L'organisation des utilisateurs permet de structurer l’Active Directory et d’appliquer plus facilement des stratégies.

1. Ouverture de la console Active Directory

  1. Ouvrir le Gestionnaire de serveur.
  2. Aller dans Outils.
  3. Sélectionner Utilisateurs et ordinateurs Active Directory.

2. Création des unités d'organisation

Dans le domaine entreprise.local, créer différentes OU.

ENTREPRISE
│
├── Utilisateurs
│
├── Ordinateurs
│
├── Groupes
│
├── Administration
│
└── Informatique
  1. Clic droit sur le domaine.
  2. Sélectionner Nouveau → Unité d'organisation.
  3. Donner un nom.
  4. Valider.

3. Création des groupes

Exemples :

GG-Administratif
GG-Informatique
GG-Utilisateurs

Choisir Type : Sécurité et selon les cas Étendue : Globale.

4. Création des utilisateurs

  1. Dans l’OU Utilisateurs.
  2. Clic droit.
  3. Sélectionner Nouveau → Utilisateur.
  4. Renseigner prénom, nom, nom d’ouverture de session.
  5. Définir le mot de passe.
  6. Configuer les options du compte.
Nom : Dupont
Prénom : Jean
Identifiant : jdupont

5. Ajout des utilisateurs aux groupes

  1. Clic droit sur l’utilisateur.
  2. Sélectionner Propriétés.
  3. Aller dans Membre de.
  4. Cliquer sur Ajouter.
  5. Sélectionner le groupe souhaité.

6. Organisation des ordinateurs

Lorsque l’ordinateur rejoint le domaine, il apparaît dans le conteneur Computers. Il est possible de le déplacer dans une OU dédiée telle que Ordinateurs.

7. Vérification

Vérifier que les utilisateurs, groupes et ordinateurs sont bien positionnés dans les bonnes OU.

Procédure 5 — VM Windows Server : Mise en place des GPO

Les GPO (Group Policy Objects) permettent d’appliquer automatiquement des règles de configuration aux utilisateurs et aux ordinateurs du domaine.

1. Ouverture de la console GPO

  1. Ouvrir le Gestionnaire de serveur.
  2. Aller dans Outils.
  3. Ouvrir Gestion des stratégies de groupe.

2. Création d'une GPO

  1. Faire un clic droit sur l’OU concernée.
  2. Sélectionner Créer un objet GPO dans ce domaine, et le lier ici.
  3. Donner un nom à la GPO.
GPO - Sécurité postes

3. Configuration d'une stratégie

Faire un clic droit sur la GPO puis Modifier.

4. Exemple : politique de mot de passe

Configuration ordinateur
→ Stratégies
→ Paramètres Windows
→ Paramètres de sécurité
→ Stratégies de comptes
→ Stratégie de mot de passe

Exemples de paramètres : longueur minimale, complexité, historique, durée maximale.

5. Exemple : verrouillage du compte

Stratégies de comptes
→ Stratégie de verrouillage du compte

Exemple : seuil de verrouillage = 5 tentatives.

6. Exemple : configuration du bureau utilisateur

Dans Configuration utilisateur → Stratégies → Paramètres d'administration, il est possible de définir des restrictions.

7. Mise à jour des stratégies

gpupdate /force

8. Vérification des GPO

gpresult /r
gpresult /h C:\gpresult.html

Ouvrir ensuite C:\gpresult.html.

9. Test avec un utilisateur du domaine

  1. Se connecter à un poste client avec un compte du domaine.
  2. Vérifier que l’utilisateur est bien dans l’OU concernée.
  3. Exécuter gpupdate /force.
  4. Vérifier que les paramètres configurés dans la GPO sont appliqués.
